# حالت‌های شکست و رفتار صحیح


## جدول B1–B15 (باگ‌های طراحی)
| # | باگ احتمالی | راه‌حل طراحی |
|---|-------------|-------------|
| B1 | تولید آیه/حدیث از حافظه | گیت «بازیابی قبل از نقل» + اسکریپت تطابق کاراکتری |
| B2 | شماره آیه/صفحه اشتباه | شمارش کانونی ۱۱۴ سوره در اسکریپت تأیید |
| B3 | درجه‌بندی ساختگی | درجه فقط از منبع نام‌دار؛ وگرنه «یافت نشد» |
| B4 | قاطی‌شدن لایه‌ها | قالب خروجی سخت‌گیرانه با برچسب |
| B5 | خرابی متن عربی | «کپی، هرگز بازنویسی» + نرمال‌سازی |
| B6 | نسبت اشتباه | ارجاع کامل + تأیید با منبع |
| B7 | قاطی‌شدن اهل‌سنت | ثبت منابع فقط-شیعه + گیت رد |
| B8 | صدور فتوا | گیت ← ارجاع به مرجع |
| B9 | «پیدا شد» دروغین | شاخه «تأیید نشد» + مسیر راستی‌آزمایی |
| B10 | خرابی API | منابع جایگزین چندگانه + رفتار آفلاین |
| B11 | تله حدیث جعلی | فهرست جعلیات + تست‌های تله |
| B12 | انحراف ترجمه | نقل انگلیسی عیناً + برچسب مترجم |
| B13 | تورم اطمینان | اطمینان گره‌خورده به وضعیت تأیید |
| B14 | دو منبع متناقض | نمایش هر دو با ارجاع |
| B15 | خروج از دامنه | مرزهای صریح دامنه |

## روبریك داور آگاه درون‌اسکیلی
| معیار | وزن | رد قطعی؟ |
|-------|-----|----------|
| هر نقل بازیابی و تأیید شده؟ | ۳۰ | بله |
| لایه‌ها جدا و برچسب‌دار؟ | ۲۰ | بله |
| درجه از منبع نام‌دار؟ | ۲۰ | خیر |
| قالب‌بندی ضدقاطی‌شدن رعایت شده؟ | ۱۵ | خیر |
| بیان معنا را تغییر نداده؟ | ۱۵ | بله |


قبولی: نمره نهایی ≥۹۹ + بدون رد قطعی فعال + هیچ معیاری <۹۰. حداکثر ۳ دور؛ بعد گزارش به کاربر.
