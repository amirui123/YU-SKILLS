# واژه‌نامه رجالی و حدیثی


| اصطلاح | تعریف |
|--------|-------|
| سند | سلسله راویان از مؤلف تا معصوم |
| متن | محتوای حدیث |
| راوی | کسی که حدیث را نقل کرده |
| ثقه | راوی مورد اعتماد |
| مجهول | راوی ناشناخته |
| مرسل | حدیثی با راوی حذف‌شده در سند |
| موثق | راوی موثق ولی غیرشیعه |
| ضعیف | راوی ضعیف یا مجهول |
| غالی | راوی مبالغه‌کننده در فضائل |
| واقفی | کسی که بر وقف امام هفتم معتقد است |
| فطحی | کسی که بر فطح (فرزند امام صادق) معتقد است |
| نجاشی | احمد بن علی نجاشی — رجال‌شناس شیعه |
| طوسی | شیخ طوسی — رجال‌شناس شیعه |
| مجلسی | علامه مجلسی — شارح کافی (مرآة العقول) |
| بهبهانی | وحید بهبهانی — درجه‌بندی روایات کافی |
